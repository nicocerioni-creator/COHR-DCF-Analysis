This report was written for FIN 43900 (AI Finance Applications, Purdue) as a learning exercise. It is not 
investment research and it is not financial advice. This project is meant to help me understand how to create 
a DC calculator via 10-K reports for public corporations with assumptions stated within dcf.py comments. A sensitivity analysis projects changes in stock price according to WACC and growth rate. A reverse DCF will also be used to check what adjustment must be made to FCFF (in millions of dollars) to return the stock price as of 9/15/2026. A conditional statement recommends deferring or buying the stock if the OCF - capex improves over 2 reporting dates. A peer P/E calculator was also created using COHR as the target with LITE and FN as peers in order to analyze COHR in comparison to similar businesses within the same industry. AI assistance: drafted with ChatGPT/Codex, created through Labs 03, 04, 05, and 06; sources gathered and verified by me; the judgments are mine. Any remaining errors are my own. Thanks!
